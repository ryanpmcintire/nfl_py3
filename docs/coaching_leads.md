## LEAD-43 predeclaration (written before scoring)

Read (`src/nfl_ats/pbp.py`, `latest_pbp_snapshot` and `load_pbp_snapshot`): the actual local instrument is `data/pbp/raw`, not `data/raw`; use the newest snapshot, select regular seasons 2013–2025 and project only needed columns per partition to limit memory.

1. Descriptive mechanism: Denver home fourth-quarter scoring margin versus its first-three-quarter margin, also report the rate-normalized difference Q4 minus Q1–3/3. Compare Denver's Q4 home margin with the league home Q4 distribution (league includes Denver); report each mean and 95% interval and the Denver-minus-league contrast. Infer Q1–3 margin from the home-oriented preplay score differential at the start of Q4; use the start of overtime as regulation end when overtime exists, otherwise the schedule final margin. Exclude games without a reliable Q4 boundary at 900 seconds and report exclusions. Q4 outcomes are descriptive only and never join into the playable flag.
2. Playable flag: BACK Denver for **all Denver home games**, approximately eight regular-season games per season, not a selected fatigue/acclimatization cell. Apply a fixed home-pick override to the existing active-model opener probability-rule predictions; every other pick stays production. Pair by game; opener pushes are excluded identically. Use the already chronological 2020–2025 active-model opener artifact with matching model id and feature-table digest. This is a fixed overlay screen on production, not a refitted feature model or independent confirmation; historical model-selection reuse is explicitly discounted. No threshold or parameter selection follows this look.
3. Oracle positive control: override only Denver home games that actually covered the opener. This deliberately uses future outcomes solely to measure instrument response; it is never a playable feature, and its larger effect cannot bound an absent smaller effect.
4. Week-blocked bootstrap, 20,000 draws, fixed seed 20260905, percentile 95% intervals and probability_positive. Report full-slate accuracy-point change, baseline/candidate accuracy intervals, affected population, changed picks and per-season effects with intervals. Descriptive contrasts use the same jointly sampled week blocks.
5. Odd/even split-half reliability: Denver season-level Q4-minus-Q1–3/3 means split by chronological within-season Denver game ordinal; Pearson correlation across seasons, with a 20,000-draw season-pair bootstrap interval. Also report each half's trait mean with a week-blocked interval. A noisy correlation estimate alone does not establish zero reliability. All results are retained; no tuning on the reliability look.

An interval or CI that contains zero is NEVER grounds to reject, fail, or close an experiment. Only two grounds ever close a line of work: (1) refuted mechanism - a RESOLVED wrong sign (whole interval on the wrong side of zero) or zero split-half reliability; (2) bounded by a positive control proven able to detect an effect that size. Everything else is unresolved_below_power: record it, report probability_positive, never the binary "contains zero". If a record command errors, the verdict is wrong, not the validator. Decisions are expected value: probability_positive above 0.5 favours playing it; state what each result implies for the DECISION before what is wrong with it. Never say a lead needs more games; the data is fixed and the project is model-limited. Report every number with its interval; no one-word verdicts.
